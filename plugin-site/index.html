Questions fréquentes

Le site génère-t-il lui-même les modèles 3D ?

Le site présente le studio. La génération se fait depuis le plugin et les outils connectés compatibles.

Les modèles sont-ils prêts à animer ?

Pas automatiquement. Le rigging, les animations et les tests dans le moteur doivent être vérifiés séparément.

Quels formats utiliser ?

GLB est souvent pratique pour le Web ; FBX est courant dans les workflows Unity. Vérifie toujours les options d'export disponibles.

Le site modifie-t-il le jeu Warworld ?

Non. Il est indépendant du serveur du jeu et ne modifie pas les fichiers de Warworld.
